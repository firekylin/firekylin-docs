# 插件安装

插件可扩展 AI 服务商、存储、搜索、通知和主题数据等能力。在独立站点项目中安装经过审核的插件包：

```sh
npm install firekylin-plugin-reading-stats
```

以上包名用于说明命名方式，安装前请确认插件实际存在、来源可信且兼容当前版本。核心会发现直接依赖和可选依赖中声明 `firekylin.type: "plugin"` 的包。也可以把本地插件放入 `plugins/<plugin-id>/`。

重启服务后检查加载日志，并按插件说明完成配置。插件运行于服务端，权限声明不是安全沙箱。卸载前备份插件数据和设置，再移除依赖或本地目录并重启。
