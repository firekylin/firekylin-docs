# AI 接入

进入系统设置 → AI 连接，选择已安装的服务商，填写插件提供的连接表单并测试连接，再选择全局默认服务商和模型。

没有需要的服务商时，可通过“添加更多 AI 服务商”查找插件，然后按[插件安装](https://github.com/firekylin/firekylin/wiki/%E6%8F%92%E4%BB%B6%E5%AE%89%E8%A3%85)完成安装。搜索不会自动安装插件。

API Key 只填写到连接设置，不要写进文章或主题。默认模型需要支持对应能力，文本模型不能仅凭名称用于图片生成。

接入后在文章编辑器试用标题或摘要生成。需要路径生成、分类建议、自动补全等功能时，到系统设置 → 智能内容中开启相应选项。

如果希望外部 AI 客户端管理博客，请阅读[AI管理](https://github.com/firekylin/firekylin/wiki/AI%E7%AE%A1%E7%90%86)。
