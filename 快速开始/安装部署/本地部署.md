# 本地部署

本地部署适合在自己的服务器上运行 Firekylin，也可用于本地开发和调试。请准备 Node.js 22.13+（22.x）或 24 及以上版本，以及 npm。

## 创建并启动站点

```sh
npx firekylin new my-blog
cd my-blog
npm start
```

按照提示选择数据库、填写站点信息并创建管理员。支持 SQLite、MySQL、TiDB 和 PostgreSQL；个人站点可以从 SQLite 开始。TiDB 使用 MySQL 协议并启用 TLS 校验。

启动后访问 `http://127.0.0.1:8360`，后台地址为 `/admin`。正式上线时请配置域名、HTTPS 和进程守护，并将站点地址改为实际访问地址。

## 本地开发

在已创建的站点目录中执行：

```sh
cd my-blog
npm run dev
```

核心程序安装在 `node_modules`，站点配置保存在 `firekylin.config.js`，默认主题复制到 `themes/firekylin`，上传文件和数据库也保存在站点项目中。不要直接修改依赖里的核心文件。

数据库已有数据时，先备份再调整连接配置，不要重新初始化覆盖旧站点。

## 参与核心开发

如果要参与核心开发，请克隆核心仓库，在仓库中按 `package.json` 的包管理器版本安装依赖，执行 `pnpm run build` 构建后台，再运行 `pnpm start`。核心源码开发与独立站点部署使用不同的目录布局。
