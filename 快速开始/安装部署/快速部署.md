# 快速部署

新版推荐使用 CLI 创建独立站点。请准备 Node.js 22.13+（22.x）或 24 及以上版本，以及 npm。

```sh
npx firekylin new my-blog
cd my-blog
npm start
```

按照提示选择数据库、填写站点信息并创建管理员。支持 SQLite、MySQL、TiDB 和 PostgreSQL；个人站点可以从 SQLite 开始。TiDB 使用 MySQL 协议并启用 TLS 校验。

启动后访问 `http://127.0.0.1:8360`，后台地址为 `/admin`。正式上线时配置域名、HTTPS 和进程守护，并把站点地址改为实际访问地址。

核心程序安装在 `node_modules`，配置、主题、上传文件和数据库保存在站点项目中。不要直接修改依赖里的核心文件。
