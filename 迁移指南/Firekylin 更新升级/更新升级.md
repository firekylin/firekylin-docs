# 更新升级

更新前备份数据库、站点配置、主题、插件和上传文件，阅读目标版本发布说明，并在副本中验证。

## 独立项目

在站点项目中更新核心依赖：

```sh
npm install firekylin@<目标版本>
```

将 `<目标版本>` 替换成已经发布并验证过的版本号，再使用原有进程管理方式重启。保留依赖锁文件以便复现版本。

## 源码和 Docker 部署

源码部署按目标版本重新安装依赖和构建后台；Docker 部署重新构建或拉取确认版本的镜像，再挂载备份过的站点数据。不要覆盖自定义配置和上传目录。

升级后检查迁移日志、后台登录、文章阅读和图片访问。回退涉及数据库结构时，需要同时恢复升级前数据库，单独降级依赖并不保证兼容。

0.x 和 1.x 用户请先阅读对应的大版本迁移指南。历史在线更新入口仅适用于支持它的旧版部署，不作为新版独立项目的更新方式。
